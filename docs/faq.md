# 常见问题

## 生成相关

**合成时报 403 / 没有声音**

微软的语音接口偶尔改校验规则。先把 `edge-tts` 升到最新：

```bash
docker compose exec tnews pip install -U edge-tts
docker compose restart
```

这只是临时补丁，容器重建就没了。要长期生效，把 `requirements.txt` 里的 `edge-tts>=` 版本号调高，再重新构建镜像。

**某一期条数很少 / 提示没抓到新闻**

多半是某个 RSS 源挂了或换了地址。看日志能逐源看到抓取结果：

```bash
docker compose logs -f tnews | grep -i "抓取\|源"
```

单个源失败不影响整体，把失效的源从 `config.yaml` 删掉或换掉即可。也可能是时间窗口太窄（`lookback_hours` 太小）——凌晨时段新闻本来就少，试试 12 小时以上。

**生成很慢 / 一直转圈**

一期大约 1～2 分钟（十几家媒体 + 5 分钟音频）。如果超过 5 分钟，看日志卡在哪一步：抓取慢多半是某个源超时；合成慢是网络到微软语音服务的问题。

**时间不对**

服务内部固定用东八区（`Asia/Shanghai`），不依赖容器时区。如果生成时刻不对，检查 `crons` 是不是标准 5 段（分 时 日 月 周），写成 6 段会在启动日志里报错。

**能不能只听某几类 / 只看国际新闻**

生成时在设置面板只勾想要的分类即可；想长期固定，就在 `programs[].categories` 里只写那几个。

**能改端口吗**

改 `docker-compose.yml` 的 `ports` 左边值（如 `"8090:18282"`），重启项目，访问地址随之变成 `http://IP:8090`。

## 访问相关

**首页什么都没有，提示「需要登录后收听」**

访客看到的是某个账号的节目，而那个账号的「速听分享」没开。两种解法：

1. 用管理员登录 → 我的账号 → 打开「速听分享」；
2. 或换一个已开启分享的账号作为首页访客：设置 → 全局管理 → 首页访客指向。

**外网访问**

不要把 18282 直接暴露到公网。推荐 Tailscale / WireGuard 回家，或在前面挂 Nginx / Caddy 加 HTTPS + Basic Auth。详见 [部署](deployment.md#反向代理与-https)。

**局域网其他设备打不开**

- 端口映射是否 `"18282:18282"`（左边是宿主机端口）
- 宿主机防火墙是否放通
- 手机和 NAS 是否在同一网段 / 有没有开 AP 隔离

**手机添加到主屏幕后图标是空白**

图标来自 `web/icon.svg`，Safari 对 SVG 图标支持有限，改用「书签」也一样能用。

## 播放相关

**播客 App 里能订阅但音频放不出来**

`config.yaml` 的 `server.public_base_url` 没配，订阅源里的音频地址是内网相对地址。填成对方能访问到的地址（如 `https://news.example.com`），重启生效。

**网页里点了播放没反应**

- 浏览器要求先有用户交互才能播放，再点一次；
- iOS 静音键拨到静音时，网页音频也会没声音；
- 极少数情况是音频文件被清理了（保留期到了），重新生成一期。

**背景音乐和新闻声音打架**

设置 → 播报 → 背景音乐，把音量降到 10～20%，或者直接关掉。

**天气播报只播一次**

设计如此：当天第一次播放**最新一期**时前置天气，之后（或听往期）直接播正片。想再听一次，清掉 localStorage 的 `nr_wx_day` 再播。

## 账号相关

**忘记管理员密码**

见 [使用 → 忘记管理员密码](usage.md#忘记管理员密码)。

**能开几个账号**

不限。每个账号的节目、源、设置互相隔离；资源占用主要是音频文件，按保留天数自动清理。

**禁用和删除的区别**

- 禁用：立即踢下线、停掉自动更新，数据保留，随时可以恢复；
- 删除：账号、节目、令牌一起删，音频文件也会清理，**不可恢复**。

## 数据相关

**数据都在哪 / 怎么备份**

全部在 `data/`：`tnews.db`（节目、用户、令牌、设置）+ `audio/*.mp3`。备份这一个目录就够了，见 [部署 → 备份与迁移](deployment.md#备份与迁移)。

**升级后页面还是老样子**

代码在镜像里，覆盖文件不重建镜像是没用的。执行 `docker compose up -d --build`，再访问 `/health` 看版本号。还不行就强制刷新（Ctrl/Cmd + Shift + R）。

**磁盘占用越来越大**

调小 `retention_days`，或管理员在设置 → 全局管理里点「清除全部往期节目」。一期 5 分钟约 5 MB。

**能在 Windows 上跑吗**

可以，`uvicorn app.main:app --port 18282` 直接跑，或用 Docker Desktop。定时任务用的是进程内调度，进程退出就不跑了，长期用建议放 NAS / 小主机。
