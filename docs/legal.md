# 版权与合规

> 下面是基于公开法规和常见实务的梳理，**不是法律意见**。涉及对外经营、上架应用商店、公司内部部署等场景，请咨询律师。

## 先给结论

| 使用方式 | 风险 |
|---|---|
| 代码开源（GitHub 公开仓库） | **低**。代码自身无第三方版权问题，许可为 PolyForm Noncommercial 1.0.0（禁止商用），依赖许可见 [CREDITS](../CREDITS.md) |
| 自己 / 家人在局域网自用 | **很低**。抓取、改写、合成都在个人欣赏范围内 |
| 给熟人小圈子分享（发个链接、播客地址） | **中低**。属于向他人提供，但通常无实际纠纷 |
| 部署到公网、对公众开放、放广告或收费 | **高**。同时踩内容著作权与新闻信息服务资质两条线 |

风险不在代码，在**内容**和**你怎么用它**。

## 一、新闻内容著作权

程序做的事：抓 RSS 里的标题和摘要 → 清洗改写 → 合成语音 → 提供在线播放 / 播客订阅。这涉及著作权法上的**复制、改编、信息网络传播**三项权利。

- **自用属于合理使用**：《著作权法》第二十四条允许"为个人学习、研究或者欣赏，使用他人已经发表的作品"。自己听、家里人听，落在这一条里。
- **分享出去就不一样了**：一旦通过「速听分享」「播客订阅」把节目给家庭以外的人听，性质就变成向公众提供，合理使用不再适用，需要权利人许可。
- **时事新闻不受保护，新闻作品受保护**：单纯的事实消息（谁在何时何地做了什么）不受著作权保护，但通讯、特写、评论、深度报道都是作品。现在抓的 RSS 摘要基本属于后者。
- **摘要比全文安全**：程序只存标题 + 一两百字摘要（`fetcher.clean_summary`），并做去重、去宣传语，不是全文转载。别改成抓正文全文，那会把风险抬高一个量级。

**已经做对的地方**：节目数据里每条都带 `source` 字段，页面上能看到来源与原文标题，相当于保留了署名线索。**别把它去掉。**

## 二、互联网新闻信息服务资质

《互联网新闻信息服务管理规定》（2017 年 6 月 1 日施行）要求：通过网站、应用程序、论坛、博客、公众账号、即时通信工具、网络直播等形式**向社会公众提供互联网新闻信息服务**，应当取得许可。

- 只给自己和家人用，**不构成**"向社会公众提供"，不涉及许可。
- 一旦放到公网、有了家庭以外的用户，即便是聚合、转载、AI 改写，也可能被认定为未经许可从事新闻信息服务；同时还牵出实名制、日志留存等《网络安全法》义务。
- **对开源项目的直接建议**：不要提供公共在线演示实例。README 写明"自托管、仅供个人与家庭使用"，把部署责任交给使用者。分享链接用可以随时吊销的令牌，比公开固定地址安全。

## 三、AI 合成内容的标识

《互联网信息服务深度合成管理规定》（2023 年 1 月 10 日施行）要求对深度合成内容（明确包含**合成语音**）进行标识，任何人不得删除、篡改标识。

- 自己听不涉及。
- 如果把合成音频公开传播（上架播客平台、公开频道、短视频配音），应当显著标明"AI 合成语音"，并在节目简介里说明内容来自哪些媒体。
- 页面上已有语音合成相关说明，公开分享时不要删掉。

## 四、语音合成接口

`edge-tts` 是对 Edge 浏览器「大声朗读」接口的第三方封装，**不是微软的公开 API**：

- 微软的服务条款一般不允许绕过官方渠道自动化调用，接口也可能随时变更、限流、加验证；
- 实际使用中，个人低频率合成几乎没有纠纷先例，但**不要商用、不要批量生成、不要转售音频**；
- 需要稳定或商用，换官方 Azure 语音服务（付费、有 SLA），或用本地 TTS（Piper 等）。

## 五、抓取行为本身

- 遵守目标站点的 `robots.txt` 与 RSS 使用条款；本项目默认每天生成 1～2 期，属于低频访问，不要改成分钟级轮询。
- 请求头里带 `TNews/1.0` 标识（`app/fetcher.py` 的 `UA`），站点能识别来源，属于加分项，别伪装成普通浏览器。
- 不要抓需要登录、付费墙或明确禁止转载的内容；内置源都是公开 RSS，可自行增删。

"TNews" 是通用组合词，作为开源项目名风险低。注意两点：不要用"XX新闻""XX资讯"这类容易与持牌新闻机构混淆的名字；不要拿媒体 logo 当图标或封面。

## 八、开源不等于免责

许可证的免责条款约束的是**代码质量责任**（出了 bug、丢了数据不赔），不能免除**内容侵权责任**。内容风险由部署和使用的人承担，所以 README 里要把这层说清楚。另外，非商业许可只能约束代码的使用方式，**不能替使用者取得新闻内容的授权**——想拿它做商业产品，除了要拿到代码的商业授权，还要自己解决内容与新闻资质的合规问题。
