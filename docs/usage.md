# 使用

## 首页与播放器

打开 `http://你的地址:18282` 就是收听页：顶部是节目名与时钟，中间是本期摘要（天气 pill、条数、时长），下面是章节列表与底部播放条。

- **章节跳转**：点任意一条新闻，音频直接跳到那一句；播放时列表里当前条会高亮
- **三种连播**：只播当期 / 正序播当日 / 倒序播当日；连播时播放条显示「连续 2/5」
- **跨日连播**（设置 → 播报）：当天播完自动接前一天，顺序跟随正/倒序
- **播放器**：锁屏控制、耳机线控、倍速（0.8×～2×）、后退 15 秒、记住上次位置
- **往期节目**：按日期分组，默认展开最近一天；连播推进到新的一天会自动展开
- **加到主屏幕**：iPhone 用 Safari「添加到主屏幕」，安卓用 Chrome「添加到主屏幕」，像一个独立 App

手机上没有 App，也不需要：网页本身就是移动端布局，可离线缓存的只有页面外壳，音频按需拉流。

## 生成一期节目

右上角 ⚙️ 打开「设置与生成」面板，选择：

| 区块 | 可调项 |
|---|---|
| 生成 | 时间范围（最近 N 小时 / 固定时段）、目标时长（10/20/25 分钟或自定义 2～120）、分类、抓取源及占比、音色、语速、播报顺序（按分类/时间/平台）、跑步模式 |
| 播报 | 今日天气、背景音乐与音量、跨日连播、睡眠暂停 |
| 数据源 | 各源生成占比、自定义 RSS |
| 自动化 | 自动更新（关闭 / 每 1～24 小时 + 开始时间） |
| 外观 | 跟随系统 / 白天 / 黑夜 |
| 全局管理（管理员） | 允许速听分享、允许播客订阅、允许接口调用、首页访客指向、往期保留、清除往期、用户管理、版本更新 |

选好后：

- **保存并生成**：保存设置并立即生成一期
- **仅保存**：只记设置，下次点右上角 ⚡ 沿用上次设置快速生成
- **重置**：恢复该档节目的默认设置

生成大约 1～2 分钟（抓十几家媒体 + 合成 5 分钟音频），期间列表顶部显示进度。

**整套设置都跟着账号走**：分类、勾选的源、语速、音色、目标时长、播报顺序、源占比保存后，以下所有生成路径都会用同一份，不用反复填——

- 右上角 ⚡ 快速生成、设置面板「保存并生成」
- 打开首页时超过 6 小时没新一期的**自动补录**（按「距上一期多久」回溯）
- 自动更新（面板里没单独存过的项，自动回退用这里保存的）
- 定点定时（跟随管理员账号保存的这整套设置，并按距上一期多久取新闻）

> 早期版本里，后台的补录 / 自动更新 / 定点定时只带了「占比」，分类和音色仍按 `config.yaml` 默认跑，所以在界面上怎么调都像没生效。1.0.4 起三者统一按账号存档执行；想看某一刻后台任务到底会用哪套参数，管理员可访问 `/api/admin/gen-options?program_id=<节目>`，或看日志里的「定点定时生成（账号 …）：分类 … · 源 … · 音色 …」。

**取参数的优先级（1.0.7 起）**：设置面板最新保存的一套 →「自动更新」里那份参数副本（只在面板缺项时兜底）→ `config.yaml` 默认值。自动更新里那份副本以前会压住新设置，出现过「改了目标时长、自动更新还按 20 分钟跑」——因为它只是上次点保存时抓的一份快照，面板之后改动不会回写。现在面板每次保存都会同步这份副本，且副本永远只是兜底。

排查用：`GET /api/admin/gen-options?program_id=<节目>` 返回 `paths`（`scheduled` 定点定时 / `ensure` 首页补录 / `auto_update` 自动更新三条路径各自实际会用的参数）和 `paths_consistent`。三者不一致说明有路径取错了值；`snapshot_found: false` 说明这个账号还没有面板存档（去设置面板点一次「仅保存」即可）。

服务端取占比的顺序是：**① 账号云同步的设置 → ② 服务端记住的「上次实际生成用的占比」→ ③ 其他账号存过的那份**。②是自愈用的：你点一次 ⚡（请求里带了占比），服务端就把这份记下来，之后后台补录 / 定时即使用不上浏览器里的设置也能沿用。所以换了设备、重建了库、或者换了账号之后，**点一次闪电就能把占比「教会」服务端**，不用专门去设置面板重存。

两个细节：

- 占比按「账号 + 节目」分开存；某源的条数不够占比名额时按实际条数计，剩余名额分给没设占比的源。
- 源地址比对做了归一化（忽略 `http/https`、末尾 `/`、主机大小写），配置里写法有出入也能对上；万一一个都没命中，日志会打印「请求带的源」和「实际抓到的源」两份清单，直接看出是哪边不一致。

## 账号与权限

| 角色 | 能做什么 |
|---|---|
| **访客** | 免登录收听（内容是管理员/指定账号的），不能生成、不能保存设置；背景音乐、连播、睡眠暂停可临时调整，仅当前会话有效 |
| **普通用户** | 注册后生成自己的节目、加自己的源、设自己的自动更新；只看到自己生成的节目 |
| **管理员** | 与普通用户同规则看自己的节目，另有：首页访客指向、往期保留与清除、用户管理（改账号/改密码/禁用/删除）、各类总开关 |

- 注册：右上角人像 → 注册。账号 2～30 字符、不含空格，可以是邮箱也可以随便起；密码至少 6 位。
- 同一台设备换账号：节目列表、正在播的音频、连播队列、设置记忆、背景音乐、播放顺序，全部切换成新账号自己的。
- 管理员禁用某账号后：立即踢下线，并停掉它的自动更新任务。

### 忘记管理员密码

数据库里只有哈希，没有明文，只能重置：

```bash
# Docker：直接把 id=1（管理员）的密码改成 newpass123
docker compose exec tnews python -c "
from pathlib import Path
from app.store import Store
from app.auth import hash_password
s = Store(Path('data/tnews.db'))
s.update_user(1, password_hash=hash_password('newpass123'))
print('已重置管理员密码')"
```

裸机把 `docker compose exec tnews` 换成 `cd /opt/tnews && .venv/bin/python` 即可。改完用 `admin / newpass123` 登录，再在「用户管理」里改成自己的密码。

> 建议平时就定期备份 `data/`，账号、设置、往期节目都在里面。

## 分享、播客订阅与外部调用

每个账号各有一套「钥匙」，互相独立，可随时吊销。入口：右上角人像 → 我的账号。

| 能力 | 地址形态 | 用途 | 前置开关 |
|---|---|---|---|
| 速听分享 | `/s/<令牌>` | 别人打开就能听这个账号的节目（只读，不能生成/改设置） | 账号自己的「速听分享」 |
| 播客订阅 | `/feed/<令牌>.xml` | 加进小宇宙 / Apple Podcasts，只含该账号节目 | 账号自己的「播客订阅」 |
| 外部调用 | `/api/latest?ext=<令牌>` 等 | 给 HA / Node-RED / 自建脚本用 | 账号自己的「外部调用」+ 管理员总开关 |

- 地址不直接摊开显示，点「复制地址」拿；
- 关掉开关 → 地址立即失效（打开会提示原因），重新开启仍是同一个地址；
- **换新令牌**：三类令牌都是纯字母数字（不带 `-` `_` 等符号）。界面上的「换新令牌」会生成一把全新令牌、**旧地址立即失效**——速听分享要把新地址重新发给对方，播客订阅要在 App 里删掉旧订阅重新添加，外部调用要同步改 Home Assistant / Node-RED 等里的 `ext=` 值（所以是两次点击确认，不会静默更换）。旧版本生成的带符号令牌也能正常用，界面会提示可换新；
- 老地址 `/feed.xml`（所有账号合集）仍然可用，之前订过的播客 App 不受影响。

鉴权规则与接口示例见 [对外接口](api.md)。

## 今日天气（可选，默认关闭）

开启后：

- 首页节目名旁常驻天气 pill（如 `☀ 杭州市 15° 有雾`），10 分钟缓存；
- 天气**单独合成一条音频**，不写进正片：当天第一次播放最新一期时先播天气（几秒）再接正片；听往期或当天再听都不会重复；
- 当天还没生成过节目也听得到：首次播放时现场补合成（约 2～5 秒）；
- 定位：优先浏览器定位（HTTPS 下可用），HTTP 被禁用时按访问端 IP 城市定位（浏览器直接查公开 IP 库，不经服务端）；也可以直接搜城市名；
- 数据来自 Open-Meteo，免费无需 Key。

设置按账号保存，每个用户看自己城市的天气。想重听天气：清掉 localStorage 里的 `nr_wx_day` 再播。

## 跑步模式

设置 → 生成 → 跑步模式，填距离（0.5～200 km）与用时（3～360 分钟），保存后右上角 🏃 一键生成：

- 时长贴合跑步时间；素材不够会自动扩大抓取窗口（最多 7 天），合成后实测偏短还会补条数重合成——宁可超一点也不会让你提前跑完；
- 顶部有一条吸顶进度条，公里刻度按配速定位（6 分钟配速时，播到第 6 分钟才显示 1 公里）；
- 背景音乐自动切「激进」节奏，播完新闻**不会自己停**（保持节奏），右侧「⏸ 音乐」手动控制；
- 跑步节目每次从头播、不前置天气，保证时长精确；期数旁与往期列表里带 🏃 距离标签。

## 背景音乐 / 睡眠暂停

- 背景音乐：轻柔（氛围）/ 激进（电子）/ 愉快（轻快弦乐），6 首 Kevin MacLeod 免版税曲目，同风格随机选一首整曲循环；音量 0～100%（Web Audio 增益，iOS 也能调）
- 睡眠暂停：到点自动暂停播放，可设 5～240 分钟

两者都是本机偏好，跟着账号同步到云端一份（换浏览器/换域名登录后自动带出）。

## 外观

默认跟随系统深浅色。点**左上角 logo** 在白天/黑夜之间切换（记在这台设备上）；设置 → 外观里可以改回「跟随系统」。

## 版本更新（管理员）

设置 → 全局管理 →「版本更新」：显示当前版本，与 `config.yaml` 里 `repo_url` 指向的 GitHub 仓库最新 Release/Tag 比对。有新版时右上角出现橙色「有新版本」，说明文字里带「查看更新 ›」直达 Release 页；没配 `repo_url`、网络不通或仓库是私有的，会显示具体原因而不是报错。检查结果后端缓存 10 分钟，点「检查更新」强制重查。升级步骤见[部署 · 升级](deployment.md#升级)。
